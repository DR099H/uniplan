Веб-приложение для студентов: расписание занятий вуза с автоматическим учётом **I и II учебной недели**, визуализацией фаз занятий в реальном времени и **персональным TODO-листом на каждый день**.

Проект разработан командой Пензенского государственного технологического университета (ПензГТУ) по дисциплине «Технологии командной разработки ПО» (практические работы №1–5).

## 🛠️ Архитектура и стек технологий

UniPlan реализован в двух полностью функциональных вариантах бэкенда при едином фронтенде:

1. **Node.js (режим быстрой локальной разработки)**:
   - Встроенные модули `node:http`, `node:sqlite`, `node:crypto` (без сторонних зависимостей из npm).
   - Автоматические тесты на `node:test` (27 тестов).
2. **PHP + MySQL (продакшен-версия на FastCGI / Nginx / IIS)**:
   - Поддержка FastCGI / PHP-FPM, ETag и `304 Not Modified`, Gzip-сжатие и кэширование статики на 1 месяц.
   - PHP 7.4/8+ с PDO MySQL.
   - Подробнее в руководстве: [`php/README-PHP.md`](php/README-PHP.md).
3. **Frontend (клиентская часть)**:
   - Vanilla JavaScript (нативные ES-модули без обязательного этапа сборки).
   - Дизайн-токены CSS Variables, Liquid Glass (стеклянные плавающие панели с аппаратным ускорением), светлая и тёмная темы, выбор акцентных палитр.
   - Скрипт сборки `npm run build` для минификации `.min.css` и `.min.js`.

## 💻 Быстрый запуск (Node.js)

Требуется **Node.js 22.13 или новее**. Устанавливать пакеты через `npm install` не требуется — проект использует встроенные возможности Node.

```bash
# 1. Запуск сервера
npm start

# 2. Откройте в браузере
http://localhost:3000
```

*(На Windows также доступен запуск двойным кликом по `start.bat`)*.

При первом запуске автоматически инициализируется база данных `data/uniplan.db` с тестовыми данными и демо-аккаунтами.

### Доступные команды:

```bash
npm start          # Запуск локального сервера разработки (порт 3000)
npm test           # Запуск 27 автотестов (логика недель, REST API, валидация)
npm run build      # Сборка и минификация CSS/JS (.min.css, .min.js)
npm run reset      # Сброс и повторная инициализация БД тестовыми данными
npm run manage --  # CLI-управление ролями пользователей и старост
```

### Демо-аккаунты для входа:
Пароль для всех демо-аккаунтов: `uniplan2026`

* `student` — студент группы 25ИП1б
* `starosta1` — староста группы 25ИП1б

## 📁 Структура репозитория

```
├── client/              # Клиентская часть (HTML, CSS, JS модули экранов)
│   ├── css/app.css      # Стили, дизайн-токены, адаптивная сетка
│   ├── js/views/        # Представления: schedule, tasks, admin, profile, auth
│   └── index.html       # Главный SPA-контейнер
├── server/              # Серверная часть на Node.js
│   ├── app.js           # Маршрутизация REST API и раздача статики
│   ├── db.js            # DDL и инициализация SQLite
│   ├── auth.js          # Хэширование scrypt и сессии
│   └── seed.js          # Начальное заполнение групп и расписания
├── php/                 # Продакшен-версия (PHP FastCGI + MySQL)
│   ├── index.php        # Роутер API и статики с ETag и кэшированием
│   ├── api/             # Модули: auth.php, db.php, week.php, validate.php
│   ├── sql/schema.sql   # DDL для MySQL
│   └── .htaccess        # Правила маршрутизации и кэширования
├── shared/              # Общий код клиента и сервера
│   └── week.js          # Алгоритм расчёта учебных недель и семестров
├── tests/               # Автотесты Node.js (27 тестов)
├── docs/                # Документация (API-контракт, тест-кейсы, JSON-шаблоны)
└── tools/               # Утилиты сборки (build.js)
```
