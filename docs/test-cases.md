# Тест-кейсы MVP UniPlan (TST-01)

Предусловие для всех кейсов: сервер запущен по README (`start.bat` или `npm start`), база с тестовыми данными (`npm run reset`).
Демо-аккаунты и пароль — в README. «Сегодня» в примерах — среда, 07.10.2026 (II неделя при начале семестра 01.09.2026).

Автоматические проверки тех же сценариев: `npm test` (тесты в `tests/`).
